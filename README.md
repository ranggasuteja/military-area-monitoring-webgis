# Military Area Monitoring & Coverage Simulation WebGIS

## 📌 Overview

Project ini merupakan **dummy project portofolio** yang mensimulasikan sistem pemantauan wilayah pertahanan menggunakan **WebGIS**. Fokus utama project adalah **visualisasi peta, analisis radius coverage, dan decision-support berbasis spasial** dengan pendekatan **non-klasifikatif dan aman untuk publik**.

Project ini dirancang untuk menunjukkan kompetensi dalam:

* GIS & Spatial Analysis
* WebGIS (CesiumJS)
* JavaScript
* Data geospasial (GeoJSON)
* Problem solving berbasis peta

---

## 🎯 Project Objectives

* Menampilkan wilayah pengamatan (simulasi)
* Mengelola titik pos pengamatan
* Menghitung radius jangkauan pengawasan
* Mengidentifikasi area ter-cover dan blind spot
* Menyediakan visualisasi pendukung pengambilan keputusan

---

## 🧩 Features

* 🌍 Interactive 3D Map (CesiumJS)
* 📍 Observation Post Management (dummy data)
* 🔵 Coverage Radius Visualization
* 📊 Coverage Area Information
* 🗂️ Layer Control

---

## 🛠️ Tech Stack

* **Desktop GIS**: QGIS
* **Web Engine**: CesiumJS
* **Spatial Analysis**: Turf.js
* **Frontend**: HTML, JavaScript
* **Data Format**: GeoJSON
* **Hosting**: GitHub Pages
